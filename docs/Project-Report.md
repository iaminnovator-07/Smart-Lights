# Project Report — Smart Lights

## Introduction

Smart Lights is a prototype automation project developed using Arduino to explore intelligent lighting systems and embedded automation concepts.

## Aim

To develop an automated lighting system capable of reducing unnecessary energy consumption.

## Components Used

- Arduino UNO
- LEDs
- LDR Sensor
- Relay Module
- Breadboard
- Jumper Wires

## Applications

- Smart homes
- Energy-saving systems
- Automation learning
- Embedded systems projects

## Conclusion

The project successfully demonstrated basic automation logic using sensors and Arduino-based embedded systems.
