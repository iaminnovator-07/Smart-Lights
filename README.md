🚀 Overview
━━━━━━━━━━━━━━━━━━

Smart Lights was one of the earliest embedded systems projects focused on understanding basic automation logic using Arduino and sensors.

The system automatically controls lights based on environmental conditions and simple automation principles.

⚙ Working Principle
━━━━━━━━━━━━━━━━━━

The Smart Lights system uses sensor-based logic to automate light control.

The LDR sensor detects surrounding brightness levels.

• During low-light conditions:
  - lights turn ON automatically

• During bright conditions:
  - lights turn OFF automatically

This helps simulate energy-efficient lighting automation systems.
